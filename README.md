# Employee Data Science Final Project

## Datasets
- `synthetic_employee_data_hidden.csv` — Supervised dataset (200 rows, 10 columns)
- `kmeans_employee_dirty_dataset.csv` — Clustering dataset (180 rows, 6 columns)

## What We Did
- Data Preprocessing & Missing Value Imputation
- Exploratory Data Analysis (EDA)
- Regression: Linear · Ridge · Lasso (target: MonthlyIncome)
- Clustering: K-Means with Elbow Method (K=3)
- Comparison: Raw vs Imputed model performance
